# Pocket Rivals privacy and data handling

Draft for publication, 2026-10-13. Add your publisher identity, contact email, and effective release date before hosting this as the public privacy policy.

Pocket Rivals is an offline game for two people sharing one device. It does not create accounts, collect personal information, send analytics or crash reports, track users, show advertising, offer purchases, or contact a backend. Game artwork, fonts, code and sound synthesis are packaged locally.

The app saves only sound/music preferences, each player's overall wins, completed match count, and draw count in local app storage (`pocket-rivals.v1`). Individual play inputs, names, contact details, location and identifiers are not collected. Native Android cloud backup is disabled. Use Settings → Reset the scoreboard to erase scores, or clear app data/uninstall to erase all preferences and local data.

In the browser version, a service worker stores the application files in the browser's cache for offline play after the initial load. Browser storage/site-data controls can remove these files. If hosted later, the hosting provider may process ordinary request logs; review that hosting arrangement and update this policy before publication. There is currently no hosted public deployment.

No app permissions are requested. Google Play or Android may independently process data under their own policies; Pocket Rivals contains no SDK to receive or transmit that information.

The game offers no social messaging, uploads, user-generated content or external game links. Review the Play target-audience and family policy requirements when selecting the final audience; no regulatory certification is claimed here.

Suggested Data safety basis: no data collected or shared by this app as implemented. The publisher must verify the release binary, dependency set and any later integrations before submitting the final declaration.
