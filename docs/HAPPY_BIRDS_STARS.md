# Happy Birds: star race and animated recovery

First to 15 actual star pickups wins. One shared gold star replaces the old survival point system; nearest contact earns the pickup, while exactly simultaneous equal contacts share it. Equal same-step finishes draw. There is no two-minute deadline. Collisions retain every collected star and never award an opponent a point.

Each collision starts that bird's own three-second recovery. The bird turns gray, eases along a curved path toward the middle, gradually regains its player color, then automatically flies again. Collision and collection are disabled while recovering; the other bird continues normally. No countdown number, cooldown bar or timer label appears. Pause and background handling freeze the animation and rules together.

Recovery.ts contains timing, easing and color interpolation; Stars.ts owns seeded placement and swept pickup checks. Positions now range across the open arena instead of two fixed side slots, avoiding active birds and the previous location. The menu illustration uses only the birds and a star, with no surrounding frame. Both stay inside the lazily loaded game module. Existing keyboard/touch controls remain. AI now targets visible stars as well as safe wall openings, using the same physics and flap restrictions. Lightweight star bursts, a thumbnail star and compact star-goal markers provide feedback without extra panels.

The initial star-race milestone passed 287 unit tests: all three difficulties complete 100 seeded real star races apiece; precise three-second recovery, independent opponent play, no collection during recovery, no duplicate scoring, terminal state, ties, spawn reproducibility and frame-rate consistency are covered. All 19 focused browser checks passed across the initial run and corrected reruns. They exercise gray/partial/full color stages, return motion, pause, input rejection during recovery, cleanup, touch controls and real tournament scoring. The Vite production build and lazy-bundle check are also run. Desktop Chrome/touch emulation is not physical Android testing.

Single-star refinement: exactly one collectible is active until the winning pickup. Seeded random positions span the open arena, reject nearby repeats and avoid active birds. The simplified preview has no nested frame. All 15 targeted unit checks and seven focused browser checks pass, including 300 seeded AI races with the new spawn logic; production build and lazy-bundle checks pass.
