# Solo arcade module

SnakeRules.ts owns the grid, fixed movement interval, two-direction input queue, safe tail movement and food spawning. SnakeGame.ts only renders/interpolates and maps pad/swipe/keyboard input. Keep movement deterministic under different render rates. Pause clears queued directions. Report finishArcade; never duel points.

Use only this module and shared contracts/helpers. Phaser owns the render loop; use fixed stepping and host-cleaned inputs. Relevant checks: tests/unit/phase3.test.ts and tests/browser/phase3.spec.ts. Arcade metadata must exclude tournaments.

SnakeSetup owns its removable DOM map/difficulty picker; Maps owns three connected static grids/palettes and previews. SnakeRules accepts map/difficulty while retaining default Meadow/Medium for legacy callers. Four fruit trigger optional golden fruit (30 points, move-count expiry shown by a ring); every eight fruit earns 40 points. Bonus points do not accelerate the snake: speed follows fruit eaten and difficulty. Food/bonus never occupy obstacles or each other. SnakeArt caches static board Graphics and interpolates a continuous rounded body with palette-specific colors. Keyboard uses InputManager.press so short taps cannot disappear between frames; swipes steer while moving. Setup, graphics and all labels are disposed. Existing global arcade best remains intact across maps. Tests: snake-maps.test.ts and snake-gardens.spec.ts.

SnakeView pools joint/link sprites in one locally generated, padded atlas. Keep black and colored layers separate, preserve grid corners, and remove all containers/texture on disposal. SnakeArt draws only eyes and fruit dynamically. Frame stalls admit at most 50ms of movement; regular 30/60/144Hz timing is unchanged. Resume preserves age and interpolation, without restarting the initial 600ms grace period.
