# Orbit Hop

Rules.ts owns deterministic game state, 25 planet types (`Planets.ts`) with varying volume, density, halo reach and fair gravity pull, plus zero-allocation arc-length trajectory previews; Game.ts and PlanetArt.ts bind input, native-FPS interpolated guides, vector planet/halo art, structured How to play planet guide and smooth miss/game-over drift transitions. Shared ArcadeGame owns lifecycle only. Fixed 120Hz steps, bounded object counts, no extra timers. Pause clears held gestures. Report finishArcade, never duel scores. Keep this module lazy and independently removable. Test with orbit-refinement.test.ts, solo-expansion.test.ts, solo-refinement.test.ts and solo-expansion.spec.ts / solo-refinement.spec.ts.
