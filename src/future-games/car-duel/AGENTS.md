# Car Duel
Custom 120Hz rigid-body approximation: mass one, angular inertia 560, circular chassis/wheel contacts, terrain normals, separating impulses and exposed head hitboxes. No Phaser physics instance. Geometry and driver locations are shared by rendering and physics. Input owns per-pointer button subscriptions; dispose/pause must clear them as well as host keys. AI drives through the same throttle/torque limits. First five wins; simultaneous deaths replay, 40-second stalled round replay, four-minute match cap. The missing reference PDF means terrain and tuning are original choices, not a claim of exact reference physics.
