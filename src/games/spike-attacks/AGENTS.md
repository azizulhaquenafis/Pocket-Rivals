# Spike Attacks

One shared 320×320 arena with three selectable layouts (Courtyard, Split Steps, Crosswind) plus seeded Random. Maps.ts owns blocks, spawns and floor colors; config derives variants from it. Each layout has three fixed rectangular cover blocks and four retracting piston lanes on every edge. ArenaPhysics is the source of truth for player radius/speed, block bounds, tip/shaft collisions and each piston's maximum legal extension. Both players share the same physical hazards and have no player-to-player collision. Rendering uses the same bounds; do not restore projectile rain or separate player arenas.

Rules owns seeded nonrepeating attack directions and `warning → extend → hold → retract → recover` phases. First five survival points; same-step deaths replay. Round resets preserve a separate 120-second foreground deadline; tied scores draw. Warnings shorten from 1.85 to 1.05 seconds, extension speed grows from 620 to 940, and holding time grows modestly. Never remove warnings or generate a pattern with no legal safe position. Keep all integration/collision checks bounded to 120Hz, with no per-frame randomness.

Spikes are 72 units wide in 80-unit lanes; gaps cannot hide a radius-nine player. Do not restore the old permanently safe grid intersections. All collision/movement, AI and rendering must use the selected map, never the default BLOCKS constant. Tests reject permanent four-direction safe spots and verify exposed AI deaths.

AI computes bounded visibility routes around expanded blocks on each new wave, then moves through the same targets and speed limits as humans. Seeded personalities select comparable safe routes; difficulty controls reaction delay and route preferences. AI cannot teleport or award points. Medium aims for shelter centers with slower reactions; Hard/Impossible search tighter safe positions. Tests run 100 seeded mixed-difficulty matches across all maps.

SpikeView interpolates positions/shaft lengths and smooths facing without writing physics. SpikeArt owns the themed arena, original characters, warning lamps and joysticks. Only human players get a joystick or drag subscription (no blue joystick in AI mode); keyboard alternatives stay in setup. Solo accepts arrows or WASD; local uses Orange WASD and Blue arrows. SpikeControls polls gamepads once per existing update (left stick/D-pad, stable player slots, drift dead zone); pause requires neutral before held gamepad input can resume. Keyboard, gamepad and touch share legal movement, with keyboard priority. No global gamepad subscriptions. Pause/cancel/release clear movement. One retained Graphics plus mask/clip, all disposed on exit. No additional RAF, physics engine, timers or textures.

Tests: spike-attacks.test.ts, expansion-framerate.test.ts, spike-shared.spec.ts and expansion-phase2.spec.ts. See docs/SPIKE_ATTACKS_REFINEMENT.md for reference observations and measured checks.
