# Fruit Duel

Rules owns seven real-fruit IDs (0–6), three decoys (7 gift, 8 medal, 9 flower), reveal suspense delays (including blank preview pauses between consecutive unsliced items), cooldowns and first-to-ten. Real fruit is guaranteed within three reveals. Any real fruit scores; there is no target-memory task. Empty/decoy swings cause 2.4s recovery and never give points to the rival; reacting slightly late after a rival already sliced a real fruit during `between` uses normal 0.85s swing recovery rather than a 2.4s stun. Successful swings recover for .85s; FirstResponse arbitrates ties. Capture the object ID at input time, before another reveal. AI sees only presented objects, uses the same tap/cooldown API, and Impossible never intentionally attacks decoys.

FruitArt owns original fruit, decoys, sleek curved katana-saber swords (crossguard, collar, wrapped grip, pommel, leading sharp cutting edge) and cut interiors. FruitGame uses retained graphics, fruit-matched split halves/droplets, natural forehand sweeping slash ribbons synced to exact blade impact (`SWING_IMPACT`), decoy recoil + clank sparks, simultaneous-tie clash sparks, full-arena tap in 1P mode, and clean edge cooldown bars (no cluttered ring over the sword handle). Both 2-Player and 1P Impossible use a tighter, more decoy-rich reveal cadence (`fruitChance: 0.28`, `0.72–1.0s` active window) while still guaranteeing a real fruit within three reveals. Pause freezes all clocks and animation; host input and global audio handle lifecycle. No new textures, workers, RAF or cross-game imports. MatchRandom supplies seeded match replay.

Tests: fruit-duel.test.ts (300 seeded AI completions plus invalid inputs/cooldown/ties/object changes), fruit-timer-effects.spec.ts, existing complete-match expansion browser check.

SwordMotion defines mirrored windup, impact, follow-through and slow return paths. Each sword returns to its original backed-away resting position after every strike. Rules and rendering share the same recovery duration/start time; input unlocks exactly when the sword reaches rest. No separate shake/tween/arc timer.
