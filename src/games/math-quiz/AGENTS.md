# Math Quiz

Banked university questions: `questions/university.json` (100 verified static questions) supplemented by procedural question families in `questions/ProceduralUniversity.ts` across 8 topics (Limits, Derivatives, Integrals, Trigonometry, Algebra, Matrices, Complex numbers, Probability) plus 4,608 exact-rational variants in `ExtendedUniversity.ts`. Each new family has independent numeric-answer and strict KaTeX checks in `university-expansion.test.ts`.
Basic arithmetic is procedurally generated in `questions/Basic.ts` across 11 categories (Addition, Subtraction, Multiplication, Division, Fractions, Percentages, Operator Precedence, Equations, Powers, Ratios, Averages) with exact rational and integer calculations and misconception-based distractors.
Repetition and uniqueness are tracked via bounded persistent history (10,000 question IDs, evicting basic entries first) in `questions/History.ts` under localStorage (`pocket-rivals.math-history.v1`), with safe fallback to memory and full-bank exhaustion reset policy; an exhausted topic stays absent until the entire university bank is used. Canonical duplicate prompts are removed, preventing infinite loops.
Every question guarantees exactly three pairwise distinct options, exactly one correct answer, two plausible misconception-based distractors, and strictly validated KaTeX LaTeX.
MathUI is a DOM overlay positioned over the logical 420x760 canvas. It includes dedicated player-local topic indicators, balanced vertical rhythm, display-mode margin resets inside buttons, and dual-axis auto-fit scaling executed upon `document.fonts.ready` and viewport resizes. Blue section rotates 180 degrees for local two-player mode on touch-primary devices only and is cleanly disposed on shutdown.
Rules coordinates scoring via FirstResponse, rewarding 1 point for the first correct answer and awarding 1 point to the opponent on errors. First to 10 points wins.
Math Quiz AI is game-local (`AI.ts`) with difficulty-calibrated latency and accuracy, never responding before question visibility.

MatchQuestions additionally persists canonical prompts for the current and previous two matches in pocket-rivals.math-matches.v1. Both basic and university selections exclude these prompts, including after bank exhaustion or a reload. Constant-RNG retries are bounded with an enumerated basic addition fallback. Answer reordering never bypasses prompt history.
Questions retain a readable 16px minimum and native horizontal/vertical scrolling. Explanations have bounded scrolling regions. MathUI owns the quiz-scroll-enabled stage class and removes it on disposal; the canvas keeps its existing touch restrictions.
Desktop keyboard bindings map `ArrowLeft`/`ArrowDown`/`ArrowRight` (plus `1`/`2`/`3`) to Orange (Player 1) answers 0/1/2 and `KeyA`/`KeyS`/`KeyD` (plus legacy `7`/`8`/`9`) to Blue (Player 2) answers 0/1/2 in local 2-player mode. Keep pre-game setup and playfield hints clean; global `H` opens instructions.
