# Math Quiz

Banked university questions: questions/university.json, generated/verified by scripts/verify-math-bank.py (development SymPy). Keep exactly three distinct answers, domains, explanation, ID, topic, estimated time. Do not introduce eigenvalue/eigenvector or lengthy computation questions. Run the verifier and KaTeX parse tests after edits. 100 questions currently cover 25 families with four variants; no independent human/student timing validation claimed. Basic questions are generated with exact integer arithmetic. Bank AI uses verified keys with calibrated accuracy/delay, not symbolic reasoning. KaTeX and fonts must remain lazy. MathUI is DOM over the shared logical canvas, rotates Blue for local play and cleans itself on exit. Rules resolves one response per question via FirstResponse.
